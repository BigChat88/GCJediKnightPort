# output/

`build.cmd` / `build.sh` (`tools/pack_iso.py`) write the disc images here:

* `openjkdf2.iso` -- Jedi Knight: Dark Forces II
* `openjkm.iso` -- Mysteries of the Sith

`work/` keeps the extracted game data between runs (delete it, or pass `--clean`,
to start over). Nothing here is committed: it contains your copy of the games.
